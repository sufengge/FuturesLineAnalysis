# K线截图分析工具（FuturesLineAnalysis）

基于 Python + OpenCV 的期货 K 线截图识别分析工具。启动程序后自动捕获桌面当前行情图，
分析均线 / 成交量 / MACD / 趋势动量，给出**每种可能走向的概率**、**操作建议**，
以及**“若必须开仓应买涨还是买跌”的强制决策**。所有结果在一个窗口内以**表格**形式呈现。

> 版本：表格优化版 v3（移除 RSI；OCR 读取真实数值与真实价位；修复 MA 小数误读、影线改真实 OHLC）

## 功能
- **一键捕获**桌面当前 K 线走势图（窗口会自动最小化后截图，再恢复）
- **表格化结果**：指标 | 评分 | 分析结论，一目了然
- **概率预判**：上涨 / 下跌 / 震荡 三种走向的概率百分比
- **操作建议**：买涨（做多）/ 买跌（做空）/ 观望
- **强制决策**：若当前必须开仓，明确给出“买涨”或“买跌”及方向置信度
- **真实数据对照（OCR）**：自动读取截图头部真实行情值（开/高/低/收、压力/支撑、
  MA1/MA2、成交量、DIFF/DEA），用于修正指标判断并直接展示
- **真实价位入场/止损**：把入场参考、止损参考从“像素 Y”换算成**具体价格**
  （如入场≈收1050、止损≈1045.7），让你清楚在哪个价位进场、哪个价位止损
- **止损参考**：在截图上用红/蓝线标注做多、做空止损参考位置
- 分析全过程在线程中执行，界面不卡顿

## 运行环境
- Python 3.10~3.12（Windows 10/11；OCR 依赖系统自带 Windows.Media.Ocr，无需安装）
- 依赖：`opencv-python`、`numpy`、`pillow`、`pyautogui`（GUI 用内置 tkinter）

安装依赖：
```bash
pip install opencv-python numpy pillow pyautogui
```

## 使用
1. 先在行情软件中把 K 线调到你常用的周期（1分/5分…），画面置于前台。
2. 运行 `main.py` 或直接运行打包好的 `KLineAnalysisTool.exe`。
3. 点击【① 捕获桌面K线图】→【② 开始分析】。
4. 查看指标表、概率条、强制决策、真实数据对照和真实价位入场/止损。

## 打包成 exe
```bash
python build.py
```
产物：`dist/KLineAnalysisTool.exe`（单文件、无控制台黑窗）。
> 首次双击若被 Windows SmartScreen/应用程序控制拦截，点“更多信息→仍要运行”放行。

## 重要配置（config.py）
- **右侧盘口面板**：如果你的行情软件右侧有盘口/逐笔面板，程序默认只分析左侧图表区
  （`ANALYZE_WIDTH_RATIO = 0.86`）；若你的软件没有右侧面板，请改为 `1.0`。
- **区域切分**：`REGION_RATIO` 按“主图 / 成交量 / MACD”三区划分，不同行情软件布局不同，
  若识别不准可微调这几个比例。
- **颜色阈值**：`COLOR_HSV` 针对黑底行情软件，若你的软件配色不同需相应调整。

## 准确性与局限
- **OCR 真实数据优先**：程序通过 Windows 自带 OCR 读取截图头部的真实数值
  （开/高/低/收、压力/支撑、MA1/MA2、成交量、DIFF/DEA），并用这些真实值修正
  MA 多空、放量/缩量、MACD 方向判断，显著提高准确性；OCR 读取失败时自动回退颜色识别。
- **真实价位映射**：用“当前K线高/低价 + 其像素位置”建立像素↔价格线性映射，
  把入场/止损换算成具体价格。若读不到价格则退回像素参考。
- **MA 小数修复（v3）**：整图 OCR 会把“MA1:1043.20”这种带小数的小字读坏（曾误读成
  1069/1069 而判成空头）。v3 对 MA 值区域单独 **10 倍放大 OCR** 并做合理性校验，
  已可准确读出 MA1=1043.20 / MA2=1042.40，均线方向据此修正。
- **影线形态（v3）**：改用 OCR 读到的最后一根 K 线真实开/收/高/低，在价格层面直接判定
  长上影与十字星，准确且不再标“估算”。
- **连续K线（v3）**：用 OCR 最后一根真实方向（收 vs 开）交叉校验像素红蓝；两者不符时
  明确提示“无法可靠统计”，避免给出虚假的连续根数。
- **红蓝占比**：该行情软件 K 线为红/绿/蓝多色渲染、且与均线同色，像素红蓝占比难以可靠
  分离，故“K线多空”仅作参考并如实标注“估算”，不同截图可能得到雷同的占比数字，不代表
  真实红蓝分布。
- 影线、红蓝占比等基于像素的指标受截图噪声影响，标注为“估算”仅供参考。
- 图像识别会受行情软件配色、缩放、清晰度影响，存在误差。
